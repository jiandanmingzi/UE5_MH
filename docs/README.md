# 项目文档导航

| 目录 | 用途 | 入口 |
|---|---|---|
| `using/` | 维护规范、当前状态、仍有待确认项的实施计划和已知问题 | [维护规范](using/README.md)、[当前状态](using/current-status.md) |
| `design/` | 当前玩法、架构、接口和未来设计 | [设计索引](design/README.md)、[项目目录规范](design/directory-structure.md) |
| `editor/` | 编辑器接线、工具、资产迁移与按需验证 | [编辑器索引](editor/README.md)、[资产整理记录](editor/asset-organization.md) |
| `reference/` | 录制真值、曲线、动作值和声音映射 | [参考数据索引](reference/README.md) |
| `archive/` | 带日期的阶段记录和维护历史，不自动成为当前待办 | [Demo阶段档案](archive/demo-2026-10-13/README.md)、[维护历史](archive/maintenance-2026-10-25/README.md) |

目录职责与当前路径见[项目目录规范](design/directory-structure.md)。原始录制、缓存、日志和回滚备份保存在对应 `Saved/` 子目录；已入库的规范曲线与逐帧真值继续保留，不按缓存清理。
