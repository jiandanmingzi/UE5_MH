## 2. 表格怎么看

| 按键写法 | 操作 / 含义 |
|---|---|
| ↑+Y | 仅Idle的突刺起手需要推左摇杆+Y；前推为本表代表，其他方向的同等突刺起手已合并。 |
| Y起手 | Idle且摇杆回中，使用上捞。 |
| 后续Y / B | 根据当前招式沿Combo边派生；例如飞远斩后单Y就是突刺，不必再写↑+Y。 |
| → | 按键先后顺序，不表示摇杆方向。 |
| （按键串）×n | 按顺序完整重复括号内按键n次；不是同时按，也不表示伤害倍率。 |

| 项目 | 含义 |
|---|---|
| 总动作值 | 完整连段的理论全中MV，不是训练木桩跳字伤害。 |
| 组合行 | 恰好在左侧时间T内完成的候选；DPS＝该组合总MV÷T。 |
| **时限最优行** | 在全部用时≤T的组合中找最大总MV，再÷T；未用完的时间仍计入分母。 |
| 同分编号 | 同样取得最高总MV的其他组合；表内优先展示实际用时更短的一组。 |

例如：1.783335秒能完成“↑+Y→Y”（突刺→袈裟），63MV；但该时限内更优的是1.525000秒完成的“↑+Y→B”（突刺→横扫），69MV。时限DPS按69÷1.783335＝38.69计算。
