## 实测段结构（`MHGZ_AerialTrajectoryRecorder` 录制，2026-09-17，11 份）

动作按 `player_motion_old_id` 的连续段切分。**不得按离地高度切分** —— 会把连续滞空的多个动作合并成一段。

| 招式 | id 链 | 说明 |
|---|---|---|
| 无白灯 后撑杆跳 | `146 → 147 → 143 → 148` | 24 次采样，链固定不变 |
| 白灯 后撑杆跳 | `158 → 159 → 148` | 34 次里 **32 次**如此；**2 次**为 `158 → 159 → 157 → 148` |
| 突进回旋斩反击 → 舞踏 | `160 → 154 → 148` | `160` 突进回旋斩 → `154` 舞踏 → `148` 落地 |
| 操虫穿刺命中 → 舞踏 | `189` | 与 `154` 同为舞踏，入口不同 |

**`157` 是白灯的下坠段，但很少出现。** 只在 `159` 跑得更长（192 帧 vs 众数 179）、下落更深（离起点 −371 cm vs 众数 −134 cm）时才接手 —— 即**弧线没够到地面的那 2 次**。常规情况下 `159` 一直覆盖到触地。

## 最早可操作帧（2026-09-18 补录 5 份 `mhrise_20260918_00*`）

**方法**：在 id 链上找**被玩家取消**的段（后继 id 与自然结束不同），取其中的**最短**时长 —— 那一段的可取消起点就是最早可操作帧。`146`/`158` 在每一份实录里都是固定 79 帧 / 0.651 s（自然长度），所以蒙太奇时间 = `0.650 + 被取消段时长`。

| 招式 | id 链 | 被取消段 | 最短 | 众数 | 蒙太奇时间 |
|---|---|---|---|---|---|
| 突进回旋斩反击 → 舞踏 | `160 → 154 → 137` | `154` | 0.316 s | 0.316（6/13） | **0.316 s** |
| 无白灯 后撑杆跳 | `146 → 147 → 137` | `147` | 0.133 s | 0.250（3×） | **0.783 s** |
| 白灯 后撑杆跳 | `158 → 159 → 137` | `159` | 0.125 s | 0.125（5×） | **0.775 s** |

后继 **一律是 `137` 空中回避** —— 三段都可以在弧中间被主动打断，印证"跳起来是为了在空中做事"。

**无白灯的 0.133 s 是孤点**（其上 0.250 出现 3 次，其余散在 0.158–0.733），按"取最早"采纳；若实测表现为过早可操作，先怀疑这一个值。舞踏 0.316（13 次里 6 次同值）与白灯 0.125（min==mode）都可信。

### 空中回避**不**继承惯性

43 个"弧 → `137`"边界上的水平速度：

| 前一段 | 它自己的水平速度 | `137` 进场后 |
|---|---|---|
| `154` 舞踏 | 8.6–9.1 m/s（紧） | 11.7–14.7 m/s |
| `147` 无白灯 | **3.1–12.1 m/s（散）** | 12.0–13.8 m/s |
| `159` 白灯 | 13.5–15.2 m/s（紧） | 12.9–14.6 m/s |

`147` 自己的速度散在 3.1–12.1（每次被取消的位置不同），而 `137` 仍稳定在 ~13 —— **与前一段无关**。若是继承或叠加模型，`137` 应跟着散。

**⇒ `137` 重置成一个自己的速度（水平 ~13 m/s）。** 这也说明 MHR 的空中位移是**速度设定式**的，不是位置播放式；项目现在用"播放录下来的位置曲线"实现它，对固定轨迹等价，但表达不了惯性语义。
