## 旧采样指导（供未测范围补录参考，不要求重录已测动作）

2. 地面滚几次后站定，让耐力完整回复；RB持续奔跑几秒后松开，再站定。
3. 分次做撑杆跳、空回、B操虫斩、瞄准操虫斩、强化操虫穿刺、觉虫击；每次之间让耐力回满。含几次命中舞踏，及起跳后不出招、单纯等待下落的情况。地面普通连招和操虫可自然打一遍，不必覆盖复杂入口矩阵。
4. F9停止即可。先读取新列健康状态，再用实际动作/输入事件区分瞬时扣除、持续扣除、回复延迟与允许回复阶段；统一原始单位后回填，不把带技能结果当基础值。
5. 复用GA的Instant/PerSecond成本、属性倍率及GAS GE实现；回复与冲刺扣耐需要补接运行时，保持单一所有者、帧率无关和死亡/卸载清理。具体阻回耐区间在样本明确后冻结设计，不提前改全部攻击为阻回耐。
