# 猎虫协同攻击实现计划

更新：2026-10-23。

状态：**突刺试点M1–M4、E1与E2已完成；用户已验收此前收尾/回手/产粉/地形版本。** 普通地面11招已保存/独立回载；首次Dodge Accept前帧冻结、0.2秒延迟及原回手规则保持。最新所有协同（含急袭）统一至少10%猎虫耐力才可起手，急袭固定终点为收招最终胶囊中心水平前方1m；Combo结束无合法后继时，俯冲抵达后释放特殊协同资格、进入普通悬停。最终编译/30项本次定向检查通过，待局部PIE，见10.16；此前34项、7项为旧版证据，不冒充本次全量重跑。

## 1. 已确认目标与边界

用户已确认：

1. 不依赖新解包的猎虫专用招式动画，用程序驱动现有猎虫模型运动。
2. 猎虫沿武器出刀轨迹飞行，**相对武器轨迹延迟0.2s**。
3. 猎虫与武器具有相同的攻击次数配置，但**分别进行真实命中判定**。武器命中不保证猎虫命中，武器落空也不禁止猎虫命中。
4. **普通延迟跟刀协同仅地面动作参与**；入口检查实际CMC落地状态，协同期间离地立即停止。急袭突刺采用10.14单独规定的留位/俯冲，不是将普通跟刀系统扩到空中。
5. **所有协同起手要求猎虫当前耐力至少为上限的1/10（含等于）**，不是额外消耗1/10，不阻止猎人GA；每招锁定本次资格，低耐起手不会因后来回耐补入，已批准者掉到10%以下仍可继续，耗尽才按原规则召回。离臂正常悬停/飞行耗耐、原回臂规则保持，不新增每段成本；操虫斩自身原1/5准备规则不属于此普通协同门槛，不改。

本计划采用的时间/空间解释：

- `0.2s`是**游戏时间**，不是固定12帧、现实时间或“蒙太奇位置减0.2”。正常60fps约12帧；全局`slomo 0.2`下，相当于约1秒现实时间。
- 记录武器实际**世界空间历史轨迹**，包含角色位移、转向、动画混合及武器挂点变化。不是将旧的角色局部轨迹重新套到角色当前位置；这是本计划的明确默认。
- 对应攻击窗口也整体延迟0.2s，不能只延迟模型、不延迟判定。
- 这里只保证完整执行时有相同的攻击机会/次数上限，不保证两者对每个目标的实际伤害次数相同。中断、资源不足或更高优先级指令可使剩余协同攻击取消。

不改变：原攻击动画/片段/入口/混合、原攻击窗口、武器命中范围/次数/动作值、输入/预输入、MM、镜头、旧操虫与特殊猎虫招式。协同不以玩家 ASC 重新激活第二个攻击GA，也不延迟角色本体的动作或连招。

## 3. 总体实现与职责

```text
现有攻击GA / Attack Collision实际窗口
    ├─ 原武器Sweep及伤害：保持原样
    └─ 虫棍专属扩展：提交源窗口身份和配置
                         ↓
Resource协同会话 ← 动画评估完成后的武器世界轨迹采样
    └─ 回放时刻 = 当前游戏时间 - 0.2s
          ├─ 驱动现有猎虫模型的位置/朝向
          └─ 回放对应窗口 → 猎虫轨迹Sweep → 独立Kinsect伤害
```

- **GA**：配置哪些段参与、提供窗口事件和结束原因，不逐帧操控猎虫，不在武器成功命中回调中补协同伤害。
- **Resource**：唯一会话/队列所有者，处理控制权、时间、生命周期、伤害快照和现有资源规则。
- **猎虫Actor**：执行同一只猎虫的轨迹驱动、朝向和既有表现；不能同时执行普通ProjectileMovement和协同位移。
- **采样/回放辅助代码**：隔离为虫棍专用小型实现单元，避免继续把全部插值、缓冲和状态分支堆入`Res_InsectGlaive.cpp`；不建立全项目通用回放框架。
- **GAS/反馈**：沿用真实猎虫伤害管道、数字、接触声音；协同不另造伤害公式。

## 4. 延迟轨迹

### 4.1 数据来源与空间

使用当前真正参与动画评估的武器Mesh（复用`WeaponTrace`及现有Mesh解析方法），采集所配置插槽的最终世界Transform。初始建议锚点为`IG_FrontTip`；可按GA改成棍尾或其他有效插槽。

- 每个GA首版使用一个明确的轨迹锚点，所有参与段共用；不能在同一时刻让一只猎虫追随两个不同端点。
- 可配置插槽局部偏移，默认零。偏移在采样时转换为世界位置，位置、视觉和攻击Sweep使用同一个结果，不得只移动模型却留下旧判定。
- 不复制武器整根棍子的TraceRegions作为猎虫范围；猎虫是沿单条路径飞行的独立实体。
- 不读原始FBX曲线代替最终武器位置，不重新播放第二份攻击动画。这样才能包含当前蒙太奇入口、内部混合、转向及真实位移。

### 4.2 采样时序与缓冲

以下是职责概念名；M1–M3已有对应实现（10.1、10.3、10.5），包括正常结束尾段和跨GA共流：

| 记录 | 必要内容 |
|---|---|
| `CoAttackSession` | RuntimeToken、会话ID/Generation、猎虫指令所有权、回放游标、状态 |
| `TrajectorySample` | 游戏时间戳、世界位置/旋转、源动作身份、连续性标志 |
| `CoAttackWindowReceipt` | 源Action身份、窗口发生ID、SegmentIndex、开始/结束时间、独立次数预算和伤害快照 |
| `TargetHitState` | 本窗口本目标的成功次数、重击时间及命中身份；不与武器表共用 |

采样须在角色/武器Mesh本帧骨骼评估完成后执行，并让猎虫回放在采样之后；使用明确的Tick依赖/更新阶段，不靠碰巧的Actor Tick顺序。Notify只记窗口事件，同帧最终姿势由采样阶段补齐。

缓冲按游戏时间维护，仅保留回放所需的历史和一个插值前驱样本；设置容量与最大可接受断档。查找包围`t - 0.2`的真实样本插值，不能每帧只读“倒数第12条”。

- 正常帧率变化、Montage PlayRate/RateScale变化、慢放：延迟仍是0.2游戏秒。
- 单独暂停攻击动画但世界时间继续：记录停住的位置，猎虫在0.2s后复现停顿；不无条件跟着本体立即冻结。
- 全局暂停：时间不推进，回放和判定均不推进。
- 历史不足：保持起飞准备/无伤害，不拿当前武器位置伪造过去的轨迹。
- 时间回退、无法恢复的断档、Mesh/Runtime失效：终止对应回放并清理；不能跨断档扫一条超长伤害线。

### 4.3 起飞、转向与返回

首版拟定只允许臂上Attached猎虫加入新会话，或正在同一协同会话中的猎虫续接；不瞬移召回远处正在执行手动指令的猎虫。

起飞过渡与收尾返回不带伤害。首个延迟攻击窗口开始时，必须已有有效历史与正确位置；若起飞未完成，则明确跳过该次协同机会，不传送、不补发伤害。测试用既有返回速度完成无判定入位，正式允许的速度/入位策略在E1确认。

跟随期间按延迟路径直接确定位置，不用普通飞行速度追赶，否则无法保持严格0.2s相位。朝向按实际路径切线处理，并遵守模型本地+Y为头部的约定；零位移保持上次有效朝向，不把Actor+X直接当虫头。

协同状态关闭普通ProjectileMovement/世界物理阻挡，避免被地板卡住或与轨迹驱动互相覆盖；保留真实Hitzone查询。首版不额外新增墙壁中止、寻路或自动追踪敌人规则。

## 5. 攻击次数、窗口与独立命中

### 5.1 延迟窗口合同

源窗口在`a`打开、`b`关闭，则猎虫窗口为：

`[a + 0.2s, b + 0.2s]`

例如武器窗口为`0.30～0.45s`，猎虫为`0.50～0.65s`；该段关闭后不能因为猎虫刚到附近就额外延长判定。

每次**实际成功打开**的源窗口生成一个新的窗口发生ID。不得把`AttackSegments.Num()`当作实际攻击次数；同一个ConfigIndex可在多个实际窗口/循环中再次出现，跳过的Section不生成窗口。

通用打开扩展点应在`ActiveCollisionWindows.Add`成功后、首帧`PerformSweepCheck`前调用，避免首帧命中导致GA结束后才补建窗口。关闭沿用现有扩展点，并核对精确窗口身份，不能让旧End关闭新窗口。

M2已保留现有直接Enable/Disable调用兼容性，同时由Notify转发`EventReference`、Mesh和Montage实例。GA在每次成功Begin时分配发生编号；引擎上下文引用和通知身份仅保存在GA，Tick更新当前引用，End必须匹配保留的Begin/最后Tick引用，不回退绑定更新的Begin。循环再次进入同一资产通知仍是新发生，资产GUID不是完整攻击身份。重开先封口旧回执，再提交新回执；打开回调后重验Action/发生编号，避免重入结束后继续首帧Sweep。不向共享Notify对象写可变运行时状态。

打开/关闭事件与姿势样本共用时间轴，不分别创建Timer。一个长帧跨过打开和关闭时，按事件顺序处理整个有效区间；开放时做零距离初始查询，关闭时补最后一段Sweep，再退役窗口。

### 5.2 次数与去重

- 初批一一对应源武器窗口。通常每目标每窗口一次；多跳段使用源段的`MultiHitCount`作为每目标上限，保留明确的重击间隔。
- 第一版仅自动支持`ContactOnly`：每一下均要真实再次接触。已有`LockedTargetTicks`段不能直接照搬“锁定目标后按Timer补伤害”，需单独评审后才能开启协同。
- 去重键包含`Runtime/Session + 源动作激活身份 + 窗口发生ID + SegmentIndex + TargetActor`。同目标不同肉质重叠时每次只选择一个有效部位，不按部位数量增加段数。
- 每次独立伤害有自己的HitInstanceID，不与武器或同窗口其他伤害共用；原IncomingHitResolver不能吞掉猎虫伤害，也不能让一个窗口每帧重复扣血。
- 源窗口被替换/中断时封口到真实结束时刻，不使用原蒙太奇预计时长继续攻击。

### 5.3 真实命中

用猎虫延迟路径的前后位置执行连续Sphere/Capsule Sweep，查询当前时刻的真实Hitzone；不是查询0.2s前敌人所在位置，也不是复用武器HitResult。

- 消费区间内经过的全部历史折线段，不只用当前帧两个远端点连线；在窗口边界裁切并做有上限的细分，避免低帧率漏扫/跨窗扫。
- 保留猎虫仅正面接触的约束，使用实际Sweep接触时的位置/朝向判断，不能先越过目标再用帧末位置过滤。
- 判定覆盖遵守项目约束：攻击判定不得小于可见攻击体积；不能因为猎虫小就让视觉接触全部漏判，也不能照搬整根武器的长条覆盖。
- 目标在0.2s中移开，猎虫可以落空；武器挥过后目标进入猎虫路径，猎虫可以单独命中。这正是独立判定的预期。

### 5.4 伤害与资源副作用

伤害来源保持Kinsect，沿用现有猎虫公式的原始动作值与肉质百分数及`/100`，不继承武器攻击力、斩味或暴击，不修改原武器段动作值。

M2已在窗口提交时快照猎虫攻击力、协同动作值、次数和间隔。延迟查询不回读可变`AttackSegments`或调用旧Ability执行伤害；目标肉质在实际命中时读取。显式快照入口与普通入口共享原GE/HitCue/数字实现，普通猎虫仍读取实时攻击力；M3已延伸到GA正常结束后的合法尾段。

拟定默认副作用：

- 协同命中不代替武器成功命中，不触发武器专属派生、卡肉、自身GE、虫印、舞踏或穿刺派生解锁。
- 不自动萃取精华；不扩展携带/UI机制。后续若要求采集，仍须先存虫、返回后交付，不能直接给角色灯。
- 命中已有虫印局部时，沿用普通`MarkedContact`产粉及共享CD；不能误用自动寻印`AutoMarkContact`或觉虫击逐次独立产粉策略。
- 耗耐已确认沿用既有`FlightDrainRate`，进入协同不允许误进ActionAttached的手臂回耐分支；耗尽由现有系统召回，剩余协同立即取消。不新增每段额外耗耐或套操虫斩1/5门槛；普通Returning原规则保持。

正式动作值、具体地面GA/灯态条件和上述未确认副作用仍须在E1前确认；正常飞行耗耐已确认，不重复询问。测试值只用于定向夹具，不写生产资产。

## 6. GA结束、连招与单只猎虫控制权

### 6.1 延迟尾段不寄存在旧GA

正常结束时，如果武器窗口刚关闭，猎虫仍需完成对应的0.2s尾段。由Resource持有已提交的不可变回执及轨迹，GA正常结束后可继续消费；不得延长旧GA、保留Attacking/输入锁或延迟角色起下一招。

回放不能因旧GA已不Active而直接拒绝所有合法尾段，也不能反过来放宽现有Notify/ActionResolver来接受任意旧回调。只有在精确活动Action下提交、未被撤销、Runtime/会话仍有效的回执才有效；旧Ability弱引用仅用于来源诊断，不用于执行伤害。

连续可协同攻击共享一条有序回放流：新GA成功提交不立即清掉前招合法尾段。同一时刻只有一只猎虫、一个世界位置；重叠窗口可有独立预算，但不能各自创建一个Actor/Tick去争抢位置。不同锚点无法连续衔接时先拒绝该配置或停止协同，不跨入口跳变扫出长伤害线。

### 6.2 已实现的结束/抢占规则（生产配置待E1）

| 情况 | 队列处理 | 猎虫表现 |
|---|---|---|
| 最后攻击窗完成 | 结束该路径采样，保留其延迟末帧，不跟随后摇；原GA正常结束仅作封口兜底 | 有连招窗等最后有效连招窗关闭即回手；无连招窗播完延迟末帧即回手，不等GA结束 |
| 接入另一个允许协同的普通攻击 | 保留前招有效历史，按真实提交顺序追加新招 | 同一条延迟流续接，不中间回臂 |
| 翻滚/主动取消进入不参与协同的动作 | 立即撤销尚未播放的攻击窗口 | 停止协同，按当前返回规则收尾 |
| 手动操虫/收虫、聚爆、操虫斩/觉虫击等特殊猎虫控制成功接管 | 先撤销协同身份及未消费窗口，再交给新指令 | 无额外尾段、重复召回或旧帧写回 |
| 自动寻印 | 协同会话/尾段期间不能抢占 | 协同完全退役后按现有规则重新评估 |
| 耐力归零、Runtime关闭/换武器、Actor失效 | 立即清理全部队列/预算/采样依赖 | 系统召回或销毁；不遗留伤害 |

动作切换须区分“新动作成功接管”与“只按下输入但激活失败”；失败Commit不取消原协同。不能只根据GAS通用`bWasCancelled`猜结束原因，因为正常连招Superseded也可能通过取消路径结束旧GA。

优先级拟定：系统失效/耗尽处理及有效手动/特殊招式指令 > 协同 > 自动寻印。协同首版不抢夺已部署的手动飞行或特殊动作租约。
