# 空中下落：现状与实现缺口

> 2026-09-24 整理。这里只保留仍有用的实现口径和未完成项；9 月 23 日空回接缝的逐轮试验与被否定修法已从本待办移除，可从 Git 历史查阅。Rise 实测数据以[下落物理](../reference/下落物理.md)及其生成器 `Scripts/MHRise/build_fall_physics.py` 为准；当前空回验收以[空回 P0/P1 方案](空回P0-P1完整修复方案.md)为准。

## 1. 已实现的下落链

| 环节 | 当前实现与边界 |
|---|---|
| 空回 `137` | `UMHGZAirDodgeAbility`、`GA_IG_AirDodge`、`AM_IG_AirDodge` 已接入；动作自身给水平约 `900 cm/s`、竖直约 `1182 cm/s` 的初速。它是玩家触发的独立动作，不是 `BeginAerialFalling` 自动产生的位移。 |
| 空回后的 `157` 表现 | `GetAerialDodgeFallMontage()` 选用 `AM_IG_AerialFall_W` 的姿势，但空回的重力仍按普通档 `2.4246 × 980 cm/s²`；白灯姿势选择与重力档不是同一件事。下落延续现有弹道，不重设空回水平速度。 |
| 系统托管下落 | `UMHGZWeaponRuntimeHostComponent::BeginAerialFalling()` 接管表现和物理；`ApplyAerialFallingPhysics()` 写入重力及空中制动，结束时由 `RestoreAerialFallingPhysics()` 恢复。普通档 `AerialFallGravityScale=2.4246`，白灯档 `WhiteAerialFallGravityScale=2.5740`，`AerialFallBrakingDeceleration=0`。 |
| 空回 `137 → 157` 接缝 | 用空回终态保持与下落蒙太奇交叉淡入消除了已录到的姿势空档；`20260923-235744` 的 7 次接缝水平速度约 `900 cm/s` 连续。生产链路自动化与可视 PIE 的最终门槛见 P0/P1 方案，不能从旧的失败录制推断现行仍有同一断点。 |

`AerialFallMaxSeconds=4.0` 是异常长时间下落的看门狗，不是终端速度或位移钳制。`157` 是 `137` 抛物线的延续；不要在下落蒙太奇起播时补写 `900 cm/s` 或为它另起一条运动曲线。

## 2. 落地水平速度：已实现，另有独立缺口

认领 `148` 落地表现时，项目按原水平朝向把速度一次性重设为 `AerialLandingHorizontalSpeed=337 cm/s`；原速度近零时取角色朝向，普通下台阶等不认领落地表现的触地不重设。`CMC.LandingSpeedReset.Applied` 在同次 CMC 更新末再次确保该值；之后交回 Walking 制动，不逐帧锁定。

`MHGZ.M5.Aerial.LandingRealTouchdownTwoEntrySpeeds` 以真实 `LandedDelegate` 覆盖约 `300/900 cm/s` 两档入速，并断言落地帧末、下一帧与单次重设。与 Rise `148` 对照应采用**落地帧末**的相位，而非把 `Spatial.csv` 中第一次看见落地蒙太奇的行误当作帧末速度。

**尚未纳入本轮的 P1-4**：到期 RootMotionSource 的 `FinishVelocity` 可能在下一帧覆盖刚写入的 `337`；历史录制 `20260923-225916` 有 2/14 次。判定重设是否执行，要查 `MovementPhases.csv` 的 `CMC.LandingSpeedReset.Queued/Applied`，不能仅查 `Spatial.csv` 下一行。该问题仍在[空回 P0/P1 方案](空回P0-P1完整修复方案.md)中列作范围外发现，不等于已经修复。

## 3. 仍需实现或确认

| 项目 | 证据与下一步 |
|---|---|
| `188` 操虫斩落空下落 | Rise 的 61 段拟合重力约 `−3101 cm/s²`（约 `3.16 g₀`），与现有 `2.4246/2.5740` 两档都不同。实现该招时需独立配置第三档，并检查 `188` 段内约 20% 的水平速度衰减；阻力机制尚未定名，不应照抄普通下落的零制动。 |
| `74` 持刀被动下坠 | Rise 记录显示进入时垂直速度重设，随后有制动和终端速度迹象。它不是普通 `143/157` 的恒加速度模型；待该分支进入制作范围时再独立拟合。 |
| 终端速度 | 当前项目 `Source/` 未找到显式 `MaxFallSpeed` 赋值；是否需要上限，仍须从 Rise 真值确认，不能根据 UE 现有下落观感猜测。 |
| 资产序列化配置 | 2026-09-16 的资产探测显示 `DA_IG_Combat` 序列化了普通/白灯重力与空中制动值。修改 C++ 类默认值后应核对该资产的实际值；新增第三档时也要验资产接线，不能只改头文件。 |

低优先级的无白灯后撑杆跳交接、落地姿态及移动退出观感已归入[项目已知的不重要问题](项目已知的不重要问题.md)，不在此重复列修复步骤。
